# TDT4145 Data Modelling, Databases and Database Management Systems

[![Databases](https://img.shields.io/badge/Databases-336791?style=for-the-badge&logo=postgresql&logoColor=white)](https://www.ntnu.edu/studies/courses/TDT4145)
[![SQL](https://img.shields.io/badge/SQL-4479A1?style=for-the-badge&logo=postgresql&logoColor=white)](https://en.wikipedia.org/wiki/SQL)
[![Data Modelling](https://img.shields.io/badge/Data%20Modelling-5C6BC0?style=for-the-badge&logoColor=white)](https://en.wikipedia.org/wiki/Data_model)

**Content:**
- Data modelling, especially entity–relationship models
- Relational databases, relational algebra, SQL, and database programming
- Database design, normalization, schemas, and data integrity
- Storage technologies, file organization, and index structures
- Query processing and database management systems
- Transactions, concurrency, and recovery

**Learning outcomes:**
- Explain database management systems, relational models, schemas, and data integrity
- Model data with entity–relationship diagrams and realize relational databases
- Use SQL, relational algebra, and database programming
- Evaluate and improve relational schemas using normalization
- Analyze and optimize database performance, including storage, indexes, and query execution
- Explain transactions, concurrency, recovery, and database reliability
